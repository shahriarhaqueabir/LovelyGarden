# LG-014 Season Calendar Upgrade

## Goal

Make seasonal planning richer and easier to filter.

## User Story

As a gardener, I want a calendar that helps me choose what to sow, transplant, and harvest.

## Scope

- Indoor/outdoor/direct sow filters.
- Harvest window view.
- Month-by-month plant cards.
- Region/hemisphere awareness.

## Definition of Done

- Calendar supports useful filters.
- Harvest windows are visible when data exists.
- Empty/missing data is handled gracefully.

## Acceptance Criteria

- Given a month is selected, calendar shows eligible plants.
- Given direct sow filter is selected, non-direct-sow items are hidden.
- Given no eligible plants, calendar explains why.
