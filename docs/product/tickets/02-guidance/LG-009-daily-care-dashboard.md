# LG-009 Daily Care Dashboard

## Goal

Add a Today view that answers: what should I do now?

## User Story

As a gardener, I want one daily dashboard for watering, planting, checking, and harvesting.

## Scope

- Today summary.
- Care tasks from rules.
- Weather-sensitive tasks.
- Quick links to relevant plant/garden.

## Definition of Done

- A daily care surface exists.
- Tasks are grouped by priority.
- Tasks link to the relevant action surface.

## Acceptance Criteria

- Given a thirsty plant exists, Today shows a watering task.
- Given seeds are in season and cells are open, Today shows planting task.
- Given no tasks exist, Today shows a calm all-clear state.
