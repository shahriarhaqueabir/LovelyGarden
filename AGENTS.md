Conventions & agent guidance (concise)
- Package manager: this repo uses `pnpm` — prefer `pnpm` for all commands.
- Styling: Tailwind CSS is used; shared UI tokens and helpers live in `src/index.css` (includes `.btn-primary`, skeletons, glass, and depth utilities).
- Visual edits: Prefer small, focused changes. Preserve decorative theme tokens like `bg-garden-*`; only convert interactive CTAs to `btn-primary` when instructed.
- DB & migrations: If you change stored shapes, add a migration under `prisma/` and update `src/db/index.ts` migration logic.
- Tests: Run `pnpm test:smoke` and `pnpm test:e2e` after UI changes. Playwright runs a `webServer` using `pnpm dev` — ensure the dev server starts cleanly.

Do / Don't
- Do: Run the local tests and create small, reviewable commits (1–3 files) for UI changes.
- Do: Link to docs rather than copying them into this file.
- Don't: Attempt GitHub operations that require secrets (`GITHUB_TOKEN`) unless the user provides them.
- Don't: Modify seed icon swaps or the typography hierarchy unless explicitly requested.

If unsure
- Ask the human reviewer for guidance on visual vs decorative tokens or when a change affects persisted data.
